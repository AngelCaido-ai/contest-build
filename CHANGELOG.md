# История изменений

Формат записи: дата — изменение — причина/контекст.

## 2026-02-11
- Добавлен фильтр `exclude_own` в `GET /listings`: при `exclude_own=true` и JWT ответ исключает листинги каналов текущего пользователя — причина: убрать self-отклик на свои размещения в каталоге Mini App.
- В каталоге Mini App (`/listings`) включён запрос с `exclude_own=true` — причина: пользователь сразу видит только чужие листинги для отклика.

## 2026-02-09
- Исправлена команда /test_deal: апсерт пользователя перед созданием тестовой сделки — причина: избежать 404 при отсутствии пользователя.
- Эндпоинт /bot/test-deal автоматически создаёт тестовый канал при отсутствии каналов у пользователя — причина: избежать 400 и позволить полностью самостоятельный тестовый запуск.
- Обновлён `docs/bot.md` — описано поведение команды /test_deal — причина: зафиксировать текущую логику.
- В уведомлении о фиксации условий сделки рекламодатель получает детали условий — причина: повысить прозрачность согласованных terms.
- Добавлен бриф рекламодателя с медиа и пожеланием времени публикации при отклике на листинг — причина: упростить первичную коммуникацию и дать пример креатива.
- Обновлён `docs/bot.md` — добавлены новые состояния FSM и эндпоинт брифа рекламодателя — причина: зафиксировать изменения в боте.

## 2026-02-08
- Обновлён `docs/next-steps.md` — добавлен этап Bot UX с детальной спецификацией: переписка по сделке (deal messages), удобный ввод даты, индикация прогресса в формах — причина: анализ показал, что «переговоры через бота» ограничены структурированными действиями, нет свободной переписки между сторонами.
- Обновлён `docs/next-steps.md` — полная ревизия плана относительно требований конкурса — причина: зафиксировать текущий статус (backend, bot, escrow, автопостинг, статистика — всё готово) и сформулировать оставшиеся задачи (Mini App UI + TonConnect, README, деплой).

## 2026-02-06
- Реализован watcher-бот (отдельный Telegram-бот) для надёжного отслеживания правок постов — причина: Bot API не доставляет `edited_channel_post` боту-автору поста, второй бот решает проблему.
- Удалён костыль `check_tampered_posts` (editMessageText/editMessageCaption) из scheduler/worker — причина: заменён watcher-ботом.
- Удалены `channel_posts` хендлеры и `UpdateLogMiddleware` из основного бота — причина: tamper detection перенесён в watcher.
- Создана документация модуля `watcher` (`docs/watcher.md`).
- Создана документация модуля `backend` (`docs/backend.md`) — причина: зафиксировать структуру, модели, API-эндпоинты, сервисы, escrow-флоу, фоновые задачи и конфигурацию.
- Создана документация модуля `bot` (`docs/bot.md`) — причина: зафиксировать структуру, команды, FSM-состояния, callback-схему, API-клиент и workflow сделок.
